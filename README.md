# NumPy – Python Programming Practice

## Overview

This repository showcases my hands-on practice with **NumPy**, a fundamental Python library for numerical computing and data manipulation.

It includes coding exercises focused on working with multidimensional arrays, performing mathematical and statistical operations, manipulating numerical data, and applying NumPy functionalities to analytical problems.

## Technical Concepts Covered

- **Array Operations:** Array creation, indexing, slicing, and element manipulation.
- **Mathematical Operations:** Sum, mean, median, minimum, maximum, and arithmetic calculations.
- **Data Filtering:** Conditional selection, filtering, and replacement of array elements.
- **Statistical Analysis:** Average, percentage calculations, sorting, and numerical analysis.
- **Matrix Operations:** Matrix addition, subtraction, element-wise multiplication, matrix multiplication, transpose, and determinant.
- **Data Normalization:** Min-Max normalization and scaling.
- **NumPy Broadcasting:** Applying operations to arrays using broadcasting.

## Technologies & Tools

- Python
- NumPy
- Visual Studio Code

## Learning Objectives

- Develop practical knowledge of NumPy for numerical computing.
- Improve problem-solving and logical programming skills.
- Understand efficient array-based computations.
- Build a strong foundation for data manipulation and analytical operations.
